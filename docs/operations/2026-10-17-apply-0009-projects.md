## Safety

- The 6 new tables are empty.
- `moderation_cases` gains two empty nullable columns. Its new CHECKs require them to be set exactly for `project_suggestion` and `correction_request` cases, and no such cases exist before this slice (their routes did not exist), so existing rows pass. If any row did not, the whole script would roll back.
- The runtime role gets read and write on the working tables, and **SELECT and INSERT only** on `project_revisions`.

**Rehearsal (2026-10-17, disposable PostgreSQL 18):** 14 entries were applied by the runner from `main` (`79f0cc8`), then the 0008 script, then this script, each as an owner role without SET on the migrator.
