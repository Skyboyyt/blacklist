## Problem

What is wrong or undecided? Keep it specific.

## Evidence

Code references, test results, measurements, documents, incidents that show the problem is real.

## Impact

What happens if we do nothing? Who or what is affected (security, privacy, correctness, cost, delivery)?

## Proposed solution

The change, in enough detail to implement and review. Include data-model, API, and migration implications.

## Alternatives considered

Each alternative with why it was not chosen. Include "do nothing".

## Consequences

Positive, negative, and follow-up work (docs to update, tests to add, threat-model changes).

## Recommendation (Claude)

Accept / reject / amend, with reasoning.

## Decision (owner)

Accepted / rejected, date, any conditions.
