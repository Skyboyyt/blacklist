# @blacklist/db

Database schema, migrations and client. **Status:** Phase7 identity/access/audit/staff application migrations are merged and deployed to Neon staging. Phase8 adds two reviewed-candidate forward migrations for seven chain-data tables; they are validated locally only and have not been applied to cloud. Existing migration bytes remain unchanged. See [operations](../../docs/operations/phase8-research.md) and [data model](../../docs/data-model.md). Required coverage, full audit and hosted identity gates remain open; no production-readiness claim.

## Responsibilities

- Drizzle schema definitions (`src/schema/<module>.ts`) mirroring [docs/data-model.md](../../docs/data-model.md), including the Better Auth models (`auth_*`) generated by its CLI and reviewed.
- **Committed SQL migrations** in `migrations/*.sql`:
  - drizzle-kit generated, or hand-written for triggers, grants, the audit append function, composite FKs and partial indexes.
- Client factory (pooling, statement timeouts) shared with pg-boss and the Better Auth adapter so jobs and auth writes can join the same transaction.
- Roles and grants:
  - `blacklist_migrator`: DDL, including the pg-boss schema;
  - `blacklist_app`: DML; INSERT/SELECT only on append-only tables; no DDL;
  - optional `blacklist_readonly`.
- Reference data seeded by migration (`chains`).

## Migration rules (ARCHITECTURE.md §27)

- Never `drizzle-kit push` against any shared database. Never edit an applied migration.
- Applied by a dedicated deploy step using `DATABASE_MIGRATION_URL`. Applications never migrate on boot, and the runtime never needs DDL.
- Expand → migrate → contract; `lock_timeout`/`statement_timeout`; `CONCURRENTLY` outside transactions; batched backfills; forward-only in production.
- CI applies all migrations to an empty database and fails on drift.
- Every migration PR completes the review checklist (locks, rewrites, data loss, backfill, grants, append-only triggers, privacy classification) and updates the data model.

May import: `@blacklist/core`. Only `@blacklist/domain` imports this package.
